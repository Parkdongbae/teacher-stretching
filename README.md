# 쉬는 시간 스트레칭 (선생님용 스트레칭 프로그램)

의자에 앉은 채로 노트북 카메라 앞에서 1~10분 동안 따라 하는 상체 스트레칭 웹앱입니다.

- **자세 인식**: 카메라로 자세를 읽어 동작이 정확한지 실시간으로 알려 줍니다 (MediaPipe Pose, 기기 안에서만 처리).
- **카메라 맞추기**: 시작 전에 노트북 화면(힌지) 각도와 거리를 안내합니다.
- **시간 설정**: 1~10분. 시간에 맞춰 루틴이 자동 구성됩니다.
- **소리**: 앱이 직접 합성하는 잔잔한 음악, 한국어 음성 안내, 전환 종소리.
- **카메라가 없어도**: 타이머 모드로 따라 할 수 있습니다.

카메라 영상은 어디에도 전송·저장되지 않습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 사이트 생성
npm test
```

## 배포

정적 사이트입니다. Vercel 에서 프레임워크 프리셋 **Vite**, 출력 폴더 `dist` 로 연결하면 됩니다.

## 판정 기준 조정

동작별 각도·거리 임계값은 `src/data/exercises.ts` 의 `THRESHOLDS`,
카메라 맞추기 기준은 `src/lib/setupCheck.ts` 의 `SETUP_RANGES` 에 모여 있습니다.
